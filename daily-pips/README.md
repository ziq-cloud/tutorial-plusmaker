# PlusMaker Daily Pips

Video 16:9 gaya notifikasi PlusMaker untuk share daily win pips di channel Telegram.

1. Buka `standalone.html` (Chrome / Edge / Safari).
2. Taip satu trade satu baris, contoh `TZB UP +120`, `TZB DOWN +85`, `TPM BUY +60`, `TPM SWAP SELL +95` (atau tekan butang cepat). Tanpa nombor pun boleh.
3. Tekan **Simpan video MP4**, kemudian **Salin caption**.
4. Hantar MP4 dalam channel (sebagai video, bukan File) dan tampal caption.

Fail sumber: `src.html` + `plate.jpg` (latar logo) + `icon.jpg` (ikon kad). Jalankan `python3 build.py` untuk jana `index.html` dan `standalone.html`.
`contoh-daily-pips.mp4` ialah contoh dengan nombor rekaan.
